합금 317종의 열역학 변수로 상(Phase)을 분류하는 머신러닝 분석

데이터: Machaka (2021), Data in Brief 38, 107346 · 분석 도구: Claude Code(AI 에이전트) + Python

배경

고엔트로피합금(HEA)이란?

  • 기존 강철: 철(Fe) 하나가 주원소, 나머지는 소량 첨가
  • HEA: 5종 이상의 원소를 비슷한 비율로 섞은 합금
    예) CoCrFeMnNi (칸토어 합금)
  • 고강도·내식성·고온 강도·저온 인성 → 차세대 구조재료 후보
  • 성질을 좌우하는 것은 결정 구조(상)
    BCC: 단단하지만 취성 · FCC: 연성·인성 우수 · 금속간화합물(Im): 매우 단단하지만 깨지기 쉬움

문제: 새 합금을 만들어 상을 확인하려면 용해·주조·XRD 분석까지 수많은 실험이 필요하다.

분석 질문: 조성에서 계산되는 열역학 변수만으로 실험 전에 상을 예측할 수 있을까? 어떤 변수가 가장 중요할까?

같은 합금이 열처리 조건만 바꿔 여러 번 기록된 경우가 많아, 처리 조건을 통일하지 않으면 같은 조성에 다른 상이 붙는 모순이 생긴다.

탐색적 분석 ①

BCC가 가장 많고, 2상(FCC+BCC)은 적다

왼쪽: 상별 합금 수 · 오른쪽: 원소별 포함 빈도. 클래스 불균형(152 vs 27)은 소수 클래스 예측을 어렵게 만든다. Fe·Cr·Ni·Co 등 철강 핵심 원소와 Ti·Nb·Zr 같은 내열 원소가 주로 쓰였다.

탐색적 분석 ②

VEC(가전자 농도)가 BCC와 FCC를 깔끔하게 가른다

상VEC 중앙값
BCC 고용체4.64
FCC+BCC7.55
FCC 고용체8.00
금속간화합물7.00

경험 규칙(VEC < 6.87 → BCC, ≥ 8 → FCC)이 데이터에서도 확인된다. 하지만 금속간화합물은 VEC 전 범위에 퍼져 있어 VEC만으로는 구분할 수 없다.

점 하나 = 합금 1종, 검은 막대 = 중앙값, 주황 점선 = 문헌의 VEC 경계값.

탐색적 분석 ③

고용체 형성 조건(δ–ΔHmix)도 금속간화합물을 걸러내지 못한다

70.5%
고용체(BCC·FCC·2상) 합금 중 영역 안에 든 비율
49.0%
금속간화합물 합금 중 영역 안에 든 비율

주황 점선 = Guo & Liu(2011)의 고용체 형성 영역(δ ≤ 6.6%, −11.6 ≤ ΔHmix ≤ 3.2 kJ/mol). 파란 점 = 해당 상, 회색 점 = 나머지. 단일 규칙의 한계 → 여러 변수를 함께 보는 모델이 필요하다.

머신러닝 ①

모델은 단순 규칙보다 25%p 더 정확하다

방법정확도Macro F1
VEC 규칙 (기준선)54.6%0.41
로지스틱 회귀74.7%0.67
랜덤포레스트80.1%0.75
그래디언트 부스팅78.2%0.72

비선형 관계를 잡는 트리 모델이 가장 좋았다. 변수 3개(Tm, Ω, 밀도)를 추가해도 성능은 거의 같았다(79–80%).

5-fold 층화 교차검증 평균, 오차 막대 = 표준편차. VEC 규칙은 금속간화합물을 예측할 수 없어 기준선이 낮다(고용체만 보면 79.7%).

머신러닝 ②

무엇이 맞고, 무엇이 틀렸나

BCC(89%)·FCC(82%)는 잘 맞히지만 FCC+BCC 2상은 56%에 그치고 37%가 금속간화합물로 오분류된다. 중요도는 VEC가 압도적이고, ΔHmix와 원자 크기 차이가 뒤를 잇는다.

왼쪽: 랜덤포레스트 혼동행렬(교차검증 예측) · 오른쪽: 순열 중요도(변수를 섞었을 때 정확도가 떨어지는 정도, 5개 fold 평균).

비판적 검토

참고 노트북의 83%는 부풀려진 숫자였다

  • SMOTE: 소수 클래스의 가짜 샘플을 만들어 불균형을 줄이는 기법
  • 참고 노트북은 SMOTE를 먼저 하고 데이터를 나눴다 → 테스트셋에 학습 데이터로 만든 합성 샘플이 섞임
  • 같은 방식으로 재현하면 88%, 올바르게(분할 후 학습 데이터에만 SMOTE) 하면 79%

오버샘플링 효과는 사실상 없었다. 전처리는 반드시 학습 데이터 안에서만 — 데이터 누수는 성능을 착각하게 만든다.

결론

정리와 한계

발견한 것

  • 열역학 변수 6개만으로 상을 약 80% 정확도로 예측
  • VEC가 핵심 변수 — BCC/FCC를 가르는 물리 법칙과 일치
  • 단일 경험 규칙(55%)보다 다변수 모델이 훨씬 우수
  • 2상(FCC+BCC)과 금속간화합물 구분이 가장 어렵다

한계와 다음 단계

  • 데이터 317종으로 작고, 2상은 27종뿐
  • ‘Im’에 Laves·σ상 등 성격이 다른 상이 섞여 있음
  • 냉각 속도 등 공정 정보는 반영되지 않음
  • 다음: 열처리 데이터 포함, CALPHAD 계산 변수 추가

의의: 실험 전에 유망한 조성을 걸러내는 1차 필터로 활용하면, 철강·합금 개발의 시행착오 비용을 줄일 수 있다.
